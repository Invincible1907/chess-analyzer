Chess Analyzer (MVP)

Quick start:
1. cd chess-analyzer
2. npm install
3. npm run dev

Usage:
- Open http://localhost:3000
- Paste a game's PGN into the textarea and click Analyze.

Notes / next steps:
- To add stronger analysis, install and integrate a Stockfish engine (server-side or WASM).
- Implement chess.com import by calling the chess.com public API and extracting PGN archives.
